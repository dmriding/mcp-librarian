# Code of Conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text lives at the link above.

## Reporting

To report a concern, email the maintainer at `david@netviper.gr` with subject prefix `[mcp-librarian conduct]`. Reports are handled confidentially.

For vulnerabilities or security-impact reports, use the channel in [SECURITY.md](SECURITY.md) instead.
